# Design documents

- [design.md](design.md): the stable system design. Changes rarely, and only through design review.
- [roadmap.md](roadmap.md): the features planned for the near future, plus open questions. Updated whenever decisions change.
- `vX.Y.Z.md`: one doc per release, containing only what that release ships. The doc whose status line reads "current WIP" is the release being worked on. A doc freezes the moment its release ships (git tag exists).
